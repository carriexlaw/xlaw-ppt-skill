## 06-point-of-view.md

## 观点 / 核心结论表达

适用：

- Strategic statement
- Key insight
- Quote
- Big idea
- Core conclusion

### Layout Patterns

- Full-image statement
- Large typography
- Big number
- Image + statement
- Minimal composition

### Rules

- 一页只讲一个观点
- 只有一句话的页用特殊页类型 `statement`（含引言；旧名 `quote` 仍可用）
  - 不带内容页标题；默认配图方式 1（全屏图 + 遮罩），要氛围化的全屏背景
  - 整页只有一个重点加粗放大（`hero:big-label`），其余都是辅助
  - 原稿里有实义的标题（如「客户原话：给我们第二个地址」）降为辅助行：放在句子下方，细体，`accent_light`；出处行用小一号 Regular
  - 元标签（「结论先行」）不上页面
- 字号阶梯 [W]

  | 句子长度（汉字）| 字号 | 行数 |
  |---|---|---|
  | ≤ 7 | 72 | 1 |
  | 8–14 | 60 | 1 |
  | 15–24 | 48–54 | 2 |
  | 25–40 | 40 | 2–3 |
  | > 40 | 不算一句话页，改要点页 | |

  - 兜底检查：文字块宽约 45–60% 页宽、高约 20–35% 页高（参照约 55% × 30%），块整体居中
  - 英文按词折行，字数按汉字当量（2 × 词数）查表，块尺寸同上
- 折行点选在标点或语义断点，各行字数尽量相等；不许孤字行，不在词中间折；折行处行尾标点省略
- 长结论挑 1–2 个重点词高亮；深色背景上用 `accent_light`
- 英文内容用英文字体
- 强观点允许大量留白
- 图片必须强化观点
- Supporting text 必须主动退后
- 不因为内容少而增加装饰

### Anti-patterns

- Decorative stock imagery
- Weak statement + excessive visual
- Too many supporting arguments
- Fake minimalism
- Oversized Statement：超过 7 个字的句子仍用 72pt，撑满页面造成视觉失衡
- Meta-label Title：「结论先行」这类元标签当标题
