## 09-cover-section-transition.md

### 封面/目录/章节页/过渡页

- Cover, Agenda, Section divider, Closing, Qutoe page

### Rules

- 封面：
  1. 大标题：
     - 字号中文50左右，英文45左右，中文需要加10%左右字距增加呼吸感，行距中文70pt/英文50pt左右
     - 字数少就放大：≤ 7 字 → 60；8–10 字 → 54；其余 50 左右（14 §3.5：45–64）
     - 颜色纯黑/纯白，注意要与背景颜色有强对比度
     - 居中显示
  2. 小标题：
     - 在大标题下方，细体放大，字号 24 左右
  3. 其它信息：细体，字号 20 左右。小字多行时两种处理：不同字重 / 颜色区分；署名和时间行放页面底部居中
  4. 图片：用大图铺满+深色遮罩模式，或者抽象流体渐变图
     - 选题先找语义：内容是什么行业 / 产品，就用它最直观的使用场景（SaaS / 软件 → 办公室里亮着屏幕的电脑、工位；制造 → 厂房；物流 → 港口）。图库里直接搜行业词（software、office workspace）通常就有
     - 找不到语义图时，最安全的是高楼 / 城市天际线：它能表达一切与商业有关的概念
     - 商务 deck 不用色调和构图像度假宣传的图（高饱和青绿泻湖、海岛、沙滩）做封面，除非内容本身是旅游相关行业；不从品牌名的字面（「北屿」→ 岛）去联想配图。深色海面、航拍自然作背景没有问题
     - 语义场景图要经得起遮罩：压上遮罩后仍认得出主体，画面整洁专业；做不到就用天际线
- 目录页：
  - 目录页要与封面有明显区分，不要用同样的背景；选题规则同封面（语义场景 → 高楼 / 天际线，不用海岛风景）
  - 目录页也要排版，按配图方式排（5 或 6）；条目字号 22–24 起，行距放开，条目块在版面内居中偏右，不是贴左上角的一段正文
  - 序号与标题区分开：英文字体加粗的数字（01–05），颜色用 `data_muted`（与 accent 同色系、灰度很重的颜色）；或用浅色圆形容器装数字。不用「一 二 三」
  - 校验（14 §3.5）：有 image 且配图方式合法、条目字号 ≥ 20 [W]
- 章节页：
  - 字号同封面大标题，或者小一点
  - 不用饱和的高亮色铺满全屏（燥）：底色用白、低饱和浅色（tertiary）或深色（secondary），高亮色只给序号或一条细线（14 C-14 [M]）
  - 章节页不是必须的，但在页数过多且内容有明显章节节奏时需要加章节页
- 一句话页（`statement`）见 06
- 中文大标题字间距：封面 / 章节 / 目录 10%，内容页 7.5%（11 字体系统）
- 不增加无意义装饰填满页面
- 与正文视觉系统保持一致
- Section page 可以提高视觉张力，但不能像换了一套模板
